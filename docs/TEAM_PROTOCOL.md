## بخش ۱ — نقش‌ها (تغییرناپذیر)

| نقش | ایموجی | مسئولیت |
|---|---|---|
| **Owner** | 👤 | تصمیم نهایی، تأیید، اجرای Termux |
| **AM** | 🧭 | بریف، هماهنگی، بازبینی، چک‌پوینت |
| **TD** | 📐 | نوشتن اسناد فنی، اسکریپت، طراحی |
| **Extractor** | 🔬 | استخراج داده، تحلیل، جستجو در Repo |
| **Patcher** | 🔧 | جراحی فایل (sed/python)، commit، push |

**قاعده طلایی نقش‌ها:**
- TD **می‌نویسد**، AM **بازبینی** می‌کند، Owner **تأیید و اجرا**.
- **هیچ‌کس نقش دیگری را انجام نمی‌دهد.**
- اگر TD گفت «من اجرا می‌کنم» → اشتباه است. اجرا فقط با Owner.
- اگر AM گفت «من می‌نویسم» → اشتباه است. نوشتن فقط با TD.

## بخش ۲ — قالب اجباری هدر پیام‌ها (تغییرناپذیر)

**قانون مطلق:** هر پیامی که توسط هر ایجنتی در چت ارسال می‌شود، **بدون استثنا** باید با این هدر شروع شود. هیچ تاریخ و ساعتی نباید در انتهای پیام نوشته شود، فقط در هدر.

```markdown
[ایموجی] **نام ایجنت — پیام #N**
تاریخ: [تاریخ منطقی] | ساعت: [ساعت تهران] | سشن: [شماره سشن]
مرجع: [موضوع پیام]
```

**مثال درست:**
```markdown
🧭 **ایجنت منیجر ۰۲ — پیام #۱۵**
تاریخ: ۱۲ نوامبر ۲۰۲۶ | ساعت: ۱۸:۳۰ | سشن: ۱
مرجع: بازبینی آیتم ۶
```

**قوانین شماره‌گذاری و سشن:**
- شمارنده هر ایجنت **مستقل** است و در شروع هر سشن **ریست** می‌شود.
- سشن ۱: عصر (قبل از ۲۲:۰۰) | سشن ۲: شب (بعد از ۲۲:۰۰).
- تاریخ منطقی = تاریخ شروع سشن (حتی اگر ساعت از نیمه‌شب گذشته باشد).
- **نقض این قانون = پیام رد شده و باید دوباره ارسال شود.**

## بخش ۶ — تله‌های فنی (تکرار نکن)

### ۱. سم nano
هرگز مارک‌داون را با `nano` پیست نکنید. از `cat > file << 'EOF'` استفاده کنید تا کاراکترهای `|` و `**` خراب نشوند.

### ۲. سم بافر پایتون
اسکریپت‌های طولانی ← همیشه `python3 -u` (ترمینال فریز نمی‌شود).

### ۳. سم `/tmp`
هیچ اسکریپتی در `/tmp` نوشته نمی‌شود. اسکریپت‌ها فقط در `tests/evidence/scripts/` (قانون R-12b).

### ۴. سم فرضیات JSON
ساختار JSON را از حافظه نگیر. با `python3 -c "import json; ..."` چک کن.

### ۵. سم Symbol Collision
در CMC، دو دارایی می‌توانند نماد یکسان داشته باشند (مثل SPX). همیشه از `cmc_id`های TEST_MAP استفاده کن.

### ۶. سم Coinbase Float
Coinbase قیمت را Float می‌فرستد و ترتیب فیلدهایش معکوس است. همیشه `parse_float=Decimal` و ترتیب `Item_08` را رعایت کن.
