## درس‌های این سشن

1. **R-23 (code fence)** — فایل markdown از چت نباید مستقیم در nano پیست شود بدون `cat heredoc` یا code fence. lesson: از `cat > file << 'END'` استفاده کن.

2. **ساختار JSON را قبل از نوشتن اسکریپت بخوان** — یک `python3 -c "import json; print(d[sym])"` ۳۰ ثانیه‌ای، از ۲-۳ دور patch جلوگیری می‌کند.

3. **پیش‌نمایش (preview) قبل از append** — `generate_appendices.py` با mode default فقط تولید می‌کند، `--append` append می‌کند. این الگو کار کرد.

4. **backup خودکار** — هر append، backup با timestamp می‌گیرد. اعتماد بالا.

5. **Split commit** — ۲ کامیت جدا (FIX-1..3 → 9b953ee، Appendix → 1a4cb0f) — هر کدام مستقل قابل revert.

6. **شف `git pull` را می‌داند** — الان نه، ولی در سشن‌های آینده اگر فایل در GitHub کامیت شده بود، اول pull بعد patch.

7. **سشن ۲ = ادامه فوری** — نه استراحت. تا آخر شب ادامه می‌دهیم.
